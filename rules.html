Arena Leaderboard Rules
PADELPILOT
RULES

Game Rules

  • Padel is played in doubles on a court smaller than a tennis court with walls that can be used to rebound the ball.
  • The ball must bounce on the ground before hitting walls.
  • The server must hit the ball underhand into the diagonally opposite service box.
  • Points are scored when the opposing team fails to return the ball according to the rules.
  • The match format is best of 3 sets; each set is first to 6 games, with a tiebreak at 6-6.

Scoring Rules

  • Points are scored as 15, 30, 40, and game, same as tennis.
  • If the score reaches 40-40, a team must win by 2 points (deuce).
  • Americano Scoring System:
    • Each match winner gets 2 points.
    • Loser gets 1 point if they win at least one game.
    • Score difference (+/-) is calculated as games won minus games lost.
    • Total points are accumulated over all rounds to determine ranking.

Randomizer Tournament Types

  • Classic 3 Point: Each player teams up with every other player once. Points collected individually.
  • Team Classic 3 Point: Each team plays every other team once. Points collected per team. Perfect for pre-defined teams.
  • Classic Americano: Each player teams up with every other player once. Points collected individually using Americano scoring.
  • Mixed Americano: All players team up with a player of the opposite sex once. Points collected individually using Americano scoring.
  • Team Americano: Each team plays every other team once. Points collected per team using Americano scoring. Perfect for pre-defined teams.
